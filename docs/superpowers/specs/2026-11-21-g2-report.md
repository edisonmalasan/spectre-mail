## C. Functional changes

- Added `apps/extension/e2e/live-domain-selection.mjs --website-cors` phase to the quarantined live probe: serves the built website with no extension and records real CORS behavior.
- Added `apps/extension/e2e/live-reception.mjs` with two modes:
  - `--prepare`: fresh persistent profile, live domain selection, real mailbox creation, writes address to gitignored `test-results/live-reception.json`, prints the exact subject/body for the user to send from their own mail app.
  - `--verify`: reopens the same profile, confirms the stored address restored, checks for mail, opens the message, and verifies sender, subject, timestamp (not epoch), body, extracted code `482731`, extracted link `https://example.com/verify`, and that the listing was retrieved from Mail.tm. Saves `test-results/live-reception.png`.
- No SMTP credential is requested or stored; the pending state is explicit and never reported as success.
- Existing shared provider/catalog/session/message code was reused, not duplicated.
