# G2 implementation plan

**Goal:** satisfy `docs/GOAL.md` G2 — unified provider experience, website multi-domain where genuinely possible, and a real reception test that does not demand SMTP credentials.

**Architecture:** keep the shared provider/catalog/session layers; add opt-in live probes for website CORS and mailbox reception; keep the website's honest automatic-only picker unless CORS evidence changes.

**Tech stack:** TypeScript/React pnpm workspace; Vitest; Playwright; OpenSpec not required for probe-only work.

**Global constraints:** no proxy/backend; no secrets committed; no invented domains; preserve Temp-Mail-inspired UI; all gates green.

## Review focus

- A blocked provider must be reported as blocked, not silently proxied.
- A pending live reception test must never be reported as passed on mocked data.
- Quarantined live probes must not run in CI or commit credentials.
