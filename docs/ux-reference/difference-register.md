## Honest limits

- No reference message with mail was received, so **inbox with mail** and **message reader** reference states are NOT INSPECTED.
- QR and Copy feedback produced no observable dialog/toast in the browser session; they are NOT INSPECTED, not "absent".
- Reference stylesheet keyframes/media rules were unreadable through the extension's cross-origin evaluation; animation timing for product UI is UNKNOWN except the four rotation animations reported by `document.getAnimations()`.
- SpectreMail's own address/message values are dynamic and must be masked in any pixel comparison.
- This register does not claim any M17 implementation. It is the input to the M17 OpenSpec migration.
