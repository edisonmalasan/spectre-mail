### Status labels used in this file

- **MEASURED** — directly observed/recorded in this session (a capture or a live DOM read exists).
- **INFERRED** — a reasoned reading of a measurement; not itself a direct observation.
- **UNKNOWN** — looked for but not obtainable (e.g. a value behind a cross-origin stylesheet, or a network log that was not captured).
- **NOT INSPECTED** — not observed in this session. This is **not** the same as "absent": no negative claim is made about it.
