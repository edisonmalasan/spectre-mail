# Independent objective UI/UX comparison — SpectreMail vs the dated Temp Mail reference

Date of this pass: 2026-11-22. Tree: `54b175d` (workspace branch `test/independent-ui-comparison`).
Reference baseline: the captures and measurements dated **2026-11-21** under `docs/ux-reference/`.
Status vocabulary: **blocker / major / minor**, plus **NOT VERIFIED** wherever a judgement cannot be made
by the instruments available here. This is a research report only: no product code, specification,
roadmap, or existing report was edited, and no finding here asks for human approval — the orchestrator
triages severity into fix tasks.

**What "objective" means here.** Every observation below is either (a) a computed CSS value, (b) a
`getBoundingClientRect()` box, (c) a count/list from the DOM or Chromium's accessibility tree, or
(d) a `document.getAnimations()` timing read. **No test in this repository reads a rendered pixel's
colour or position, and this pass did not either.** Whether a type scale or a colour _looks_ like the
reference is a judgement no tool here can make and is marked NOT VERIFIED rather than rated.
Font-family strings and computed colours are recorded as values, not as aesthetic judgements.

## E. Explicitly NOT VERIFIED

1. **Rendered-pixel colour and position.** No instrument here reads a pixel. Every colour and box in
   this report is a computed style or a `getBoundingClientRect()` read. Whether the violet accent, the
   type scale or the spacing _look_ like Temp Mail is a human judgement and is deliberately not rated.
2. **Live incoming mail / populated inbox / message reader / OTP and link extraction against a real
   provider.** No external sender is configured; all provider responses in the browser tier are
   recorded. The reference itself never captured those states (`reference-inventory.md` S05/S06).
3. **The QR dialog effect, reference popovers/menus/dialogs (S08), article link targets (I25), and
   Premium/account/app routes (X01–X05).** Out of scope or not inspected in the dated evidence; no
   claim is made about them.
4. **Real clipboard success** (see D) and **any browser other than Chromium**.
5. **Per-route reference geometry at 956/768/390/360.** The dated captures cover only the home page at
   those widths, so the nine article routes can be measured but not compared at non-desktop widths.
6. **The 20 px desktop reference-height discrepancy** between the PNG IHDR (4261) and the recorded
   `scrollHeight` (4281). Recorded as a measurement difference; its cause was not investigated.

## F. Triage summary

- **Major (actionable, objective):** (1) home page 60 % of reference length — but currently an
  approved deviation; (2) toolbar geometry/shape; (3) address-field structure (input vs static code);
  (4) "Popular Articles" renders 0 links against the reference's 6 — a stale limitation now that all
  routes exist; (5) 7 of 9 reference URLs land on the product instead of the article.
- **Minor:** header +2 px, band −21 px, panel +20/−4 px and border/radius/padding values, title type
  values, in-field Copy 48 vs 52 px, footer geometry (approved deviation), missing 150 ms Copy-button
  feedback animation, and two per-route Premium/form/contact-form deviations (all approved).
- **Confirmed pass with no finding:** Copy tooltip timing/opacity is an exact match; all 50 route ×
  viewport combinations render with no horizontal overflow; every article route has its own H1 and
  sections; the website browser tier is green at 51/51; no rendered-pixel judgement is claimed.
